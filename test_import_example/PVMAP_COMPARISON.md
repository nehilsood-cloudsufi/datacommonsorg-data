## 1. BIS Central Bank Policy Rate

### Input Data Overview
- **Source:** Bank for International Settlements
- **Content:** Central bank policy rates for countries (Argentina, United Kingdom)
- **Columns:** FREQ, REF_AREA, TIME_PERIOD, OBS_VALUE, UNIT_MEASURE
- **Rows:** 30 observations

### Sample Input Data
```csv
FREQ:Frequency,REF_AREA:Reference area,TIME_PERIOD,OBS_VALUE,UNIT_MEASURE
M: Monthly,AR: Argentina,1993-04,0.63,368: Per cent per year
D: Daily,GB: United Kingdom,2009-09-08,0.5,368: Per cent per year
```

### PV Map Comparison

| Aspect | Ground Truth | Claude Generated | Analysis |
|--------|--------------|------------------|----------|
| **Dataset Identifier** | `populationType=FinancialInstrument`<br>`instrumentType=CountryCentralBankPolicyRate` | `populationType=EconomicActivity`<br>`economicActivityType=CentralBankPolicyRate` | Different but both valid |
| **REF_AREA** | `observationAbout={Data}` | `#Regex,"(?P<CountryCode>[A-Z]{2}): .*"`<br>`observationAbout=country/{CountryCode}` | **Claude better** - extracts ISO code |
| **Frequency** | `measurementQualifier=Monthly/Daily`<br>`observationPeriod=P1M/P1D` | `observationPeriod=P1M/P1D` | Claude missing measurementQualifier |
| **TIME_PERIOD** | `observationDate={Data}` | `observationDate={Data}` | Match |
| **OBS_VALUE** | `value={Number}` | `value={Number}` | Match |
| **Unit** | `unit=PercentPerAnnum` | `unit=PercentPerAnnum` | Match |

### Ground Truth PV Map

### Claude Generated PV Map

## Key Observations

### 1. Place Resolution
Claude consistently improves place resolution:
- **BIS:** Extracts ISO country codes via regex
- **SAIPE:** Constructs school district DCIDs
- **India NSS:** Maps 30 state names to Wikidata IDs
- **UNdata:** Maps city name to explicit Wikidata ID

### 2. Schema Completeness
Claude adds properties that improve data quality:
- `statType` (measuredValue, marginOfError)
- `measurementMethod` (ACS_5YearEstimate, CDC_SVI)
- `dcs:` prefixes for Data Commons standard values

### 3. Column Coverage
For complex datasets, Claude maps significantly more columns:
- **CDC SVI:** 273 lines vs 47 lines (5.8x more comprehensive)
- Maps E_*, M_*, EP_*, MP_*, EPL_*, SPL_*, RPL_*, F_* series

### 4. Semantic Precision
Ground truth sometimes uses more domain-specific types:
- **Zurich:** `BirthEvent` vs `Person` (ground truth more precise)
- **India NSS:** `medicalCondition` vs `healthCondition`

### 5. Data Quality Directives
Ground truth includes data quality features Claude doesn't generate:
- `#Aggregate` for handling duplicates
- `#Filter` for excluding invalid values
- `#ignore` for problematic records

---

## Recommendations

### For Claude-Generated PV Maps

1. **Review populationType choices** - Ensure domain-specific types are used when available (e.g., `BirthEvent` for birth data)

2. **Add data quality directives** - Consider adding `#Filter` for zero/negative values where appropriate

3. **Validate place mappings** - Verify Wikidata IDs are correct for mapped locations

4. **Check property names** - Ensure properties match Data Commons schema (e.g., `medicalCondition` vs `healthCondition`)

### For Ground Truth PV Maps

1. **Add explicit place mappings** - Consider pre-resolving places to DCIDs when possible

2. **Include statType** - Add `statType=measuredValue` for clarity

3. **Add measurementMethod** - Document data source methodology
