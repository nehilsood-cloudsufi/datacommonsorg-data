# Employment Category

Employment statistics, labor force data, unemployment rates, and workforce indicators.

## Datasets

| Dataset | Description | Country | Geographic Levels |
|---------|-------------|---------|-------------------|
| bls_ces | US BLS Current Employment Statistics - National | USA | country |
| bls_ces_state | US BLS Current Employment Statistics - State Level | USA | state |
| nces_employed_college_grads | US NCES Employed College Graduates Statistics | USA | country |
| doctoratedegreeemployment | NCSES Doctorate Degree Employment | USA | state |
| southkorea_employment | South Korea Employment Statistics | South Korea | country, region |
| mongolia_employment | Mongolia Employment Data | Mongolia | country, region |
| ncses_median_annual_salary | NCSES Median Annual Salary Data | USA | country |
