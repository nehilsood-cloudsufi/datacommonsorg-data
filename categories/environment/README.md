# Environment Category

Environmental data including fires, floods, climate, and sustainability indicators.

## Datasets

| Dataset | Description | Country | Geographic Levels |
|---------|-------------|---------|-------------------|
| inpe_fire | INPE Brazil Fire Event Count | Brazil | country, state |
| flood_insurance_claims | FEMA National Flood Insurance Claims | USA | state, county |
| oecd_wastewater_treatment | OECD Wastewater Treatment Data | Global | country |
| google_sustainability_financial_incentives | Google Sustainability Financial Incentives | Global | country, state |
