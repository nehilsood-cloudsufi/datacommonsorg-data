# Economics Category

GDP, income, prices, consumer indices, commodity markets, exchange rates, and economic indicators.

| brazil_sidra_ibge | Brazil SIDRA IBGE - Income, Economic Statistics | Brazil | country, state |
| india_rbistatedomesticproduct | India RBI State Domestic Product | India | country, state |
| india_rbi_state_statistics | India RBI Statistics - prices, wages | India | country, state |
| oecd_quarterly_gdp | OECD Quarterly GDP Growth Rates | Global | country |
| world_bank_commodity_market | World Bank Monthly Commodity Prices | Global | global |
| bis_central_bank_policy_rate | BIS Central Bank Policy Rates | Global | country |
| fao_currency_statvar | FAO Currency and Exchange Rate Data | Global | country |
