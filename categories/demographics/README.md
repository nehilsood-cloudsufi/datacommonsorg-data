# Demographics Category

Population statistics, census data, age/sex/race distributions, births, deaths, and demographic indicators.

## Datasets

| Dataset | Description | Country | Geographic Levels |
|---------|-------------|---------|-------------------|
| us_census_pep_asrh | US Census Population Estimates by Age, Sex, Race, Hispanic Origin | USA | country, state, county |
| us_cdc_single_race | US CDC Single Race Demographics Data | USA | country, state |
| zurich | Zurich Population - total, by age, sex, origin, births | Switzerland | city |
| india_nfhs | India National Family Health Survey - demographics | India | country, state |
| ireland_census | Ireland Census - birthrates, death rates, population | Ireland | country, county, city |
| singapore_census | Singapore Census Demographics | Singapore | country |
| southkorea_demographics | South Korea Demographics Statistics | South Korea | country, region |
| new_zealand_census | New Zealand Census - demographic data | New Zealand | country, district, city |
| mongolia_demographics | Mongolia Population by region, age, sex, urban/rural | Mongolia | country, region |
| uae_population | UAE Population Data from Emirates Statistics | UAE | country, emirate |
| kenya_census | Kenya Census Demographic Data | Kenya | country, county |
| rwanda_census | Rwanda Census Demographic Data | Rwanda | country, district |
| ethiopia_statistics | Ethiopia Statistics - demographic data | Ethiopia | country, region |
| mexico_census_aa2 | Mexico Subnational Population Statistics | Mexico | country, state, municipality |
| subnational_demographics_stats | World Bank Subnational Demographics | Global | country, subnational |
